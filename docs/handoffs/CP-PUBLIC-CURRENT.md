### Decisão de arquitetura — 2026-10-12 (America/Sao_Paulo)

Para a implementação do grant temporário de `/config/`, o provedor inicial de persistência é Supabase Postgres Free, sem adotar Supabase Auth: `admin`/`staff` continuam no Netlify Identity. Persistir apenas dados mínimos em colunas PostgreSQL normais, usar hashes para tokens bearer, migrations portáveis e uma interface de armazenamento; não usar codificação opaca própria nem consultas artificiais para impedir pausa por inatividade. Aceita-se restaurar um projeto pausado; disponibilidade contínua exigirá rever plano/provedor. Gmail fica decidido como primeiro transporte de email, atrás de adaptador. Grants/sessões começam com 3 horas; `admin` e `staff` podem emitir/revogar, com prova de email por resgate explícito de token único e consumo atômico. Aceita-se que a remoção de uma role interna só tenha efeito no próximo login/refresh do Identity. Exportação externa e restauração devem ser definidas/testadas antes de produção.
