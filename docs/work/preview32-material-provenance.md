# Registro de materiais do preview 32

## Escopo

Este recorte reutiliza os nove materiais locais que estavam versionados no
commit `73e7cf2` (deploy preview 32). Eles foram transplantados de forma
seletiva para a branch de reconciliação, exclusivamente como apresentação de
acabamentos e pedras. Preços, estado, fingerprint e regras comerciais não
vieram daquele commit.

## Estado de proveniência

- Origem técnica: `app/assets/materials/` do commit `73e7cf2` deste mesmo
  repositório.
- Uso atual: textura de interface e de acabamento visual.
- Autoria, licença e autorização comercial externa: **não documentadas neste
  repositório**.
- Decisão: os arquivos podem ser tratados como assets locais rastreáveis para
  revisão interna, mas não devem ser descritos publicamente como texturas
  licenciadas/autorizadas até que a documentação de origem seja anexada.
